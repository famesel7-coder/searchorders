# Current task — Client Search MVP under IA-5

Дата: 2026-09-28

## Цель

Построить систему поиска зарубежных клиентов для I’MON, которая не просто собирает компании, а проверяет коммерческие гипотезы и показывает только тех кандидатов, для которых есть подтверждаемая причина контакта.

## Ограничение

Тендеры исключены из активного поиска по решению пользователя.

## Рабочие гипотезы

- H1: прямой outbound по buying signals.
- H2: агентства и консалтинг как white-label / subcontract партнёры.
- H3: компании перед конференциями, выставками и product launches.

Ни одна из гипотез заранее не считается лучшей.

## Пайплайн

### 1. Hypothesis

Для найденной компании система формулирует конкретную гипотезу:

> «Компания X может нуждаться в услуге Y сейчас, потому что произошло событие Z».

Без события/основания лид не проходит дальше.

### 2. Verify

Система должна собрать подтверждения:
- официальный сайт компании;
- первоисточник события;
- дата;
- география;
- тип бизнеса;
- размер/стадия компании, если доступно;
- релевантная услуга I’MON;
- подходящий decision-maker role;
- минимум один проверяемый факт, объясняющий timing.

### 3. Challenge

Перед попаданием в shortlist система ищет причины не тратить время:
- событие может не создавать дизайн-потребность;
- услуга уже могла быть закуплена;
- компания слишком мала или слишком велика;
- нет подходящего decision maker;
- нет релевантного кейса I’MON;
- рынок/язык/юридические ограничения;
- сигнал слабый или устарел.

### 4. Conclude

На выходе один из статусов:
- `strong` — есть подтверждённый повод и понятный outreach angle;
- `verify_more` — сигнал интересный, данных недостаточно;
- `reject` — контраргументы сильнее гипотезы.

## Карточка лида

Обязательные поля:
- company;
- website;
- country;
- channel;
- signal_type;
- signal_date;
- hypothesis;
- evidence[];
- counter_evidence[];
- proposed_service;
- decision_maker_role;
- relevant_case;
- confidence;
- conclusion;
- source_urls[];
- outreach_angle;
- status.

## Интерфейс

Вместо общего score без объяснения показывать:
- «Почему это может быть клиент»;
- «Что подтверждено»;
- «Что вызывает сомнение»;
- «Что предлагаем»;
- «Кому писать»;
- «Вывод».

Все тексты интерфейса — на русском. Оригинальные названия компаний и ссылок не переводятся.

## Экспериментальная аналитика

По каждому каналу считать:
- найдено;
- прошло verify;
- strong;
- outreach;
- replies;
- positive replies;
- calls;
- proposals;
- wins;
- revenue;
- time per qualified lead.

## Ближайшая реализация

1. Убрать тендерный поток из dashboard.
2. Разделить discovery на H1 / H2 / H3.
3. Добавить evidence / counter-evidence.
4. Добавить conclusion вместо одного score.
5. Добавить enrichment компании и decision-maker role.
6. Начать логировать реальные результаты outreach.
