# Запуск MVP

Обновлено: 2026-08-12

## Что уже работает

Команда получает свежие публикации HH.ru или локальный JSON, затем:

1. нормализует объявления;
2. находит сигналы проектной и штатной работы;
3. определяет услуги и отрасль;
4. исключает штатные вакансии;
5. считает релевантность I’MON;
6. выбирает кейс с прямой ссылкой;
7. формирует черновик ответа;
8. сортирует лиды по очередям hot, review, archive и rejected.

## Установка

Требуется Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e .
```

## Тесты

```bash
python -m unittest discover -s tests -v
```

Тестовый прогон использует четыре примера:

- premium real estate web-проект;
- штатная UX/UI-вакансия;
- backend-вакансия;
- проект презентации для автомобильной конференции.

## Проверка без внешнего API

```bash
search-orders evaluate tests/fixtures/sample_leads.json \
  --output output/sample-results.json
```

## Сбор с HH.ru

Анонимный поиск вакансий не требует API-токена.

```bash
search-orders hh \
  --hours 72 \
  --max-results 100 \
  --area 1 \
  --area 2 \
  --output output/hh-leads.json
```

По умолчанию выполняются запросы по проектному web-дизайну, брендингу, UX/UI, Tilda/Webflow/Framer и презентациям. Свои запросы можно передавать повторяемым параметром:

```bash
search-orders hh \
  --query "проектная работа корпоративный сайт" \
  --query "разовая задача брендинг" \
  --hours 48
```

Для каждой предварительно подходящей публикации система запрашивает полное описание. Для быстрого диагностического запуска можно отключить это:

```bash
search-orders hh --skip-details --max-results 10
```

## Формат результата

Верхний уровень JSON:

- generated_at;
- summary с количеством лидов по очередям;
- items — отсортированные результаты.

Каждый результат содержит:

- исходную карточку лида;
- решение фильтра и найденные сигналы;
- общий балл и разбивку;
- выбранный кейс;
- черновик предложения.

## Известное ограничение текущей проверки

В рабочей облачной среде прямой smoke-test HH.ru вернул HTTP 403 `forbidden`. Официальная документация допускает анонимный поиск вакансий, поэтому коннектор не требует токена; окончательная проверка сетевого вызова должна быть выполнена локально или на сервере развертывания. Формат ответов, преобразование данных и весь последующий pipeline покрыты офлайн-тестами.
