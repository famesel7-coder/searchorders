# Project rules — Search Orders

Дата фиксации: 2026-09-25

## Единый источник правды

Репозиторий `famesel7-coder/searchorders` является основной рабочей базой проекта по поиску зарубежных клиентов для I’MON Digital Agency.

Все новые данные и результаты по проекту должны сохраняться в репозитории, а не оставаться только в переписке.

Сюда относятся:
- архитектура системы и технические решения;
- список и описание источников лидов;
- поисковые фильтры и критерии качества;
- конфигурация стран, отраслей, услуг и минимальных чеков;
- код сборщиков и нормализации;
- модели скоринга;
- структура базы лидов;
- промпты AI-анализа;
- документация по запуску;
- принятые коммерческие и продуктовые решения;
- журнал изменений и результаты тестов.

## Принцип обновления

1. Новое существенное решение фиксируется в репозитории.
2. Изменения конфигурации отражаются в соответствующих config/data-файлах.
3. Новые источники сопровождаются описанием происхождения данных и ограничений использования.
4. Неподтверждённые гипотезы явно помечаются как гипотезы.
5. Секреты, API-ключи, пароли и персональные credentials в репозиторий не коммитятся.
6. Репозиторий должен позволять восстановить текущее состояние проекта без необходимости искать решения в истории чата.

## Текущий MVP

Тендеры исключены из активной стратегии поиска клиентов.

На первом этапе система строится вокруг трёх каналов:
- прямой outbound по компаниям с buying signals;
- агентства и консалтинговые компании как white-label / subcontract партнёры;
- компании перед конференциями, выставками и запусками продуктов.

Система должна:
- находить свежие сигналы спроса;
- нормализовать компании и события;
- оценивать вероятность потребности в услугах I’MON;
- определять, что именно можно предложить;
- находить подходящую роль decision maker;
- подбирать релевантный кейс I’MON;
- готовить персонализированный outreach;
- сохранять решения «в работу / пропустить».
