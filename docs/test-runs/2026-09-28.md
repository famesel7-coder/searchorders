## False positives removed by the new rules

Examples removed from the high-priority output:

- Mechanical & Electrical Design Consultant Services
- SaaS Backup & Recovery Solution
- generic advertising/media procurement with no explicit I’MON service match
- landscape/technical design notices that only carried generic design-support CPVs
- duplicate notices for the same buyer + project title

## Current limitations

1. SAM.gov needs a local API key before US procurement can be tested.
2. Public tenders are only one channel; the system still needs direct commercial buying signals (funding, launches, rebrands, expansion).
3. The scorer is deterministic and transparent; AI enrichment has not yet been added.
4. Tender qualification barriers (required turnover, local references, language, legal entity, insurance, framework conditions) are not yet extracted.

## Next implementation step

Add a direct-company signal stream and an enrichment layer that produces:

- company
- trigger event
- likely service need
- estimated commercial potential
- suggested decision-maker role
- qualification/risk notes
- source URL
- outreach angle

### Current state

The MVP now has two distinct discovery tracks:

1. **Open demand** — published tenders / procurement opportunities.
2. **Latent demand** — companies with strong buying signals such as funding, rebranding or expansion.

Both tracks run from the same CLI command and write separate JSON/CSV outputs.
