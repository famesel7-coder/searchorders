# Search Orders

Система автоматического поиска проектных заказов для I’MON Digital Agency.

## Цель

Ежедневно находить свежие проектные запросы на брендинг, UX/UI, сайты, digital-продукты, презентации и разработку; исключать штатные вакансии; оценивать релевантность; исследовать задачу и компанию; подбирать подходящий кейс и готовить персонализированный отклик.

## Принцип работы

1. Сбор публикаций из разрешённых источников.
2. Нормализация и удаление дублей.
3. Жёсткое исключение штатных вакансий.
4. Исследование задачи и компании.
5. Скоринг релевантности.
6. Подбор кейса I’MON.
7. Создание индивидуального предложения.
8. Подтверждение перед отправкой.
9. Сохранение результата и обратной связи.

## Репозиторий как база знаний

- `docs/` — архитектура и рабочие процессы.
- `knowledge/` — профиль агентства, услуги, ограничения и позиционирование.
- `data/` — структурированные настройки поиска и каталог кейсов.
- `decisions/` — принятые архитектурные и коммерческие решения.

Все новые факты должны фиксироваться здесь с источником и датой проверки. Неподтверждённые предположения помечаются отдельно.

## Текущий статус

Реализован первый работающий срез MVP:

- сбор свежих публикаций через официальный API HH.ru;
- нормализация вакансии в единую карточку лида;
- определение проектных и штатных сигналов;
- жёсткое исключение постоянной занятости;
- определение услуг и отрасли;
- скоринг 0–100;
- подбор релевантного кейса I’MON;
- создание черновика персонального отклика;
- JSON-выгрузка, готовая для n8n, Telegram или CRM.

## Быстрый запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .

python -m unittest discover -s tests -v
search-orders evaluate tests/fixtures/sample_leads.json
search-orders hh --hours 72 --max-results 100 --area 1 --area 2
```

Результат сохраняется в `output/leads.json`. Подробности: [docs/mvp-usage.md](docs/mvp-usage.md).

Для ежедневного запуска на небольшом Ubuntu VPS подготовлены Docker Compose и systemd timer: [docs/vps-deployment.md](docs/vps-deployment.md).

## Безопасность отправки

На текущем этапе система только готовит черновики. Автоматическая отправка откликов отключена и будет добавлена после калибровки на 30–50 вручную проверенных лидах.
