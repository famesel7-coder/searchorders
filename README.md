# Search Orders

Система автоматического поиска проектных заказов для I’MON Digital Agency.

## Цель

Ежедневно находить свежие проектные запросы на брендинг, UX/UI, сайты, digital-продукты, презентации и разработку; исключать штатные вакансии; оценивать релевантность; исследовать задачу и компанию; подбирать подходящий кейс и готовить персонализированный отклик.

## Принцип работы

1. Сбор публикаций из разрешённых источников.
2. Нормализация и удаление дублей.
3. Жёсткое исключение штатных вакансий.
4. Исследование задачи и компании.
5. Скоринг релевантности.
6. Подбор кейса I’MON.
7. Создание индивидуального предложения.
8. Подтверждение перед отправкой.
9. Сохранение результата и обратной связи.

## Репозиторий как база знаний

- `docs/` — архитектура и рабочие процессы.
- `knowledge/` — профиль агентства, услуги, ограничения и позиционирование.
- `data/` — структурированные настройки поиска и каталог кейсов.
- `decisions/` — принятые архитектурные и коммерческие решения.

Все новые факты должны фиксироваться здесь с источником и датой проверки. Неподтверждённые предположения помечаются отдельно.


## Рабочий MVP — 2026-09-28

Сейчас реализовано:

- TED: тендеры Германии и Нидерландов;
- UK Find a Tender: тендеры Великобритании;
- SAM.gov: адаптер готов, нужен локальный `SAM_API_KEY`;
- коммерческие buying signals из публичных RSS: TechCrunch Venture, EU-Startups, Silicon Canals;
- нормализация и удаление дублей;
- прозрачный скоринг 0–100;
- защита от ложных совпадений по техническим/инженерным design CPV;
- JSON/CSV выдача;
- локальный HTML-dashboard с кнопками «В работу / Пропустить»;
- автоматический перевод заголовков и описаний заказов/сигналов на русский язык с локальным кешем и fallback на оригинал;
- regression tests и GitHub Actions CI.

### Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/main.py --top 20
```

После запуска создаются:

- `data/leads_latest.json`
- `data/leads_latest.csv`
- `data/signals_latest.json`
- `data/signals_latest.csv`
- `data/dashboard.html`

### SAM.gov

Секреты не коммитятся. Для США:

```bash
export SAM_API_KEY="..."
python src/main.py
```

Либо хранить ключ локально в `.env`/менеджере секретов.

## Два типа лидов

### 1. Open demand

Публично опубликованные заказы и тендеры с дедлайном, заказчиком и прямой ссылкой.

### 2. Latent demand

Компании с сигналами потенциальной покупки: funding, rebrand, expansion. Такие кандидаты сначала получают статус `needs_enrichment` и не считаются подтверждёнными заказами до дополнительного исследования.

## Следующие этапы

1. Enrichment: сайт, отрасль, размер компании, страна, decision maker.
2. Qualification: требования тендера, язык, оборот, опыт, юридические ограничения.
3. AI-анализ: что именно предложить I’MON и какой кейс показать.
4. Персонализированный outreach с обязательным подтверждением перед отправкой.
5. Развёртывание dashboard на постоянном URL.
